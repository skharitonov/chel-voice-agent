## Вывод

**Лучший вариант для русского языка при минимальной цене — Gemini Flash Live (~2–3¢/мин) или Inworld TTS (~3.5¢/мин).** Retell/Vapi/Bland упомянуты как полностековые решения, но оценки качества на русском нет. Cartesia — явные проблемы с ударениями на русском.

## Детальный обзор по платформам

### Inworld TTS — фаворит автора канала

Автор канала последовательно отслеживает Inworld с середины 2025 года.

**Realtime TTS-2** ([пост 2158](https://t.me/ai_product/2158), май 2026)
- **#1** на [artificialanalysis.ai/text-to-speech](https://artificialanalysis.ai/text-to-speech/leaderboard) — выше OpenAI, Gemini, ElevenLabs
- Русский: ✅ (100+ языков, crosslingual — тембр сохраняется при смене языка)
- Цена: **$0.035/мин** (Google $0.037, Cartesia $0.039, ElevenLabs $0.10)
- Задержка: **<200 мс**
- Совместим с OpenAI Realtime API
- Ключевые фишки: Voice Direction (режиссёрские ремарки в скобках), Conversational Awareness (слышит предыдущие реплики), клонирование голоса по 15 сек

**TTS 1.5** ([пост 1878](https://t.me/ai_product/1878), январь 2026)
- Mini: **$0.005/мин**, Max: **$0.01/мин** — рекордно дёшево
- Русский: ✅ (15 языков)
- Задержка: Mini <130 мс, Max <250 мс
- На 30% эмоциональнее, на 40% меньше ошибок WER

**Open source** ([пост 1444](https://t.me/ai_product/1444), июль 2025)
- Выложили код и руководство на GitHub: [github.com/inworld-ai/tts](https://github.com/inworld-ai/tts)
- В примерах — 600 часов разнообразной речи; для русского данных «добыть не проблема»
- Можно дообучить на русском и развернуть локально

---

### Gemini Flash Live — самый дешёвый полный пайплайн

**Gemini 3.1 Flash Live** ([пост 2055](https://t.me/ai_product/2055), март 2026)
- Заточен под realtime голосовых агентов (видео и голос одновременно)
- 90+ языков, включая русский
- «Звучит и реагирует гораздо человечнее» предыдущей версии
- Хорошо фильтрует фоновый шум (важно для промышленных условий)
- Цена: ~**$0.02–0.03/мин**

> *«Можно собрать примерно в 6 раз дешевле на Gemini»* — сравнение с Grok ($0.05/мин)

Автор сам делал на Gemini Flash переводчик в реальном времени.

### Grok Voice Agent API

([пост 1820](https://t.me/ai_product/1820), декабрь 2025)
- Speech-to-speech, **#1 на бенчмарках** Artificial Analysis на момент релиза
- На русском: *«порвал OpenAI Realtime в клочья»*
- Цена: **$0.05/мин** — «не сильно дёшево»
- Вывод автора: для тех, кому нужна максимальная скорость и качество и можно платить премиум

---

### ElevenLabs Conversational AI

([пост 951](https://t.me/ai_product/951), декабрь 2024)
- Полный пайплайн: STT + LLM + TTS в одном месте
- Выбор LLM: Gemini, GPT, Claude или своя модель
- Базы знаний, SDK (Python, JS, React, Swift), WebSocket API
- Цена: **$0.10/мин**, на больших объёмах — до **$0.015/мин**
- Вывод автора: *«Ну, с этим уже можно работать»* — при высоких объёмах

## Рекомендация для прототипа

**Сценарий A (квалификация) и B (поиск ЛПР) — рекомендованный стек:**

```
STT:  Whisper (локально) или Deepgram Nova-2
LLM:  Claude Sonnet / GPT-4o mini
TTS:  Inworld TTS 1.5 Mini ($0.005/мин) или Gemini Flash Live (всё в одном)
Телефония: Twilio (SIP trunk) или Vapi как обёртка
```

**Самый быстрый старт:** Gemini Flash Live — speech-to-speech, один API, русский из коробки, ~$0.02–0.03/мин, уложится в бюджет $10–20 на 500–1000 минут тестовых звонков.

**Если нужна гибкость в промптах и контроль над диалогом:** собирать самому на Twilio + Inworld TTS 1.5.
