## 1. Выбор архитектуры: STT→LLM→TTS vs end-to-end

([пост 1285](https://t.me/ProductsAndStartups/1285), июнь 2025 — Байрам говорил с фаундерами голосовых AI компаний)

**Проблема мультимодальных LLM** (типа GPT-4o Voice, Gemini Flash Live):
- Теряют контекст на разговорах длиннее 5–7 минут
- Начинают повторять сказанное ранее
- Голосом это особенно раздражает — нельзя пролистать, приходится слушать

**Почему STT → LLM → TTS лучше для cold calling:**
- Можно делать постобработку: «отрезать» ненужные части транскрипта перед подачей в LLM
- Контекст под контролем — можно управлять тем, что модель «помнит»
- Более предсказуемое поведение в длинных сценариях

**Проблема данных для тренировки моделей:**
> «Многие лабы тренировали свои модели на аудиокнигах, но эти записи сильно отличаются от реальных разговоров по интонации, паузам, перебиваниям и "чистоте" языка»

Это объясняет, почему TTS-модели иногда звучат «книжно» — особенно актуально для имитации живого звонка.

**Главная задача голосового агента:**
> «Задача voice AI стартапа — не научиться наиболее точно воспроизводить человеческий голос, а научиться "режиссировать" диалог: что скрыть, что оставить»

Применительно к нашей задаче: агент должен **управлять темпом и инициативой**, а не просто озвучивать скрипт.

## 2. Практическая реализация: LiveKit + OpenAI Realtime API

([пост 1521](https://t.me/ProductsAndStartups/1521), ноябрь 2025)

Видеолекция курса AI Product Engineer — **готовый код и 2 архитектуры**:
- Связка: **LiveKit + OpenAI Realtime API**
- Готовый голосовой агент за 15 минут
- Видео: [youtu.be/cgfcxUQCgQw](https://youtu.be/cgfcxUQCgQw)

LiveKit — open source инфраструктура для realtime аудио/видео, хорошо интегрируется с OpenAI Realtime API. Подходит для прототипа.

## 3. Реальный кейс: onsa.ai — AI cold calling агент

([пост 1687](https://t.me/ProductsAndStartups/1687), март 2026)

Стартап из экосистемы канала делает голосового агента специально для холодного обзвона:
- Использовали «философию autoresearcher» для тестирования агента без живых людей → добились улучшения параметров → перешли к тестам с бизнес-пользователями
- Сайт: [onsa.ai](https://onsa.ai)
- **Ограничение: только US/UK/EU** — на русский рынок не ориентированы

Полезно как референс архитектуры и подхода к тестированию.

## 4. Управление несколькими голосовыми агентами

([пост 1577](https://t.me/ProductsAndStartups/1577), декабрь 2025)

Принцип «числа Данбара» применительно к агентам:

> «Управлять 7 coding-агентами ≠ управлять 7 голосовыми агентами колл-центра. Там, где ошибка дорогая и "проверка смысла" сложнее "проверки механики", человеческий контроль становится жёстким ограничением»

Для cold calling это означает: нужен **human-in-the-loop** — агент квалифицирует, человек принимает решение о передаче лиду.

Как снизить нагрузку на контролирующего человека:
- Guardrails и детерминированные проверки
- Самопроверки у самих агентов
- Мониторинг качества в продакшне
- Переход от «ревью всего» к «ревью по триггерам + выборочная проверка»

## Итоговые рекомендации для TASK.md

| Инсайт | Применение в прототипе |
|--------|----------------------|
| STT→LLM→TTS лучше для длинных сценариев | Начинать с этой архитектуры, не с Gemini end-to-end |
| LiveKit + OpenAI Realtime — проверенная связка с кодом | Смотреть видео лекции как стартовую точку |
| Cold calling требует «режиссуры» диалога | Промпт агента — не скрипт, а набор тактик и переключений |
| Human-in-the-loop обязателен | Агент квалифицирует → отчёт → менеджер решает |
| onsa.ai — референс архитектуры | Изучить их подход к тестированию агента |

### Рекомендованный стек для прототипа (уточнённый)

```
Телефония:    Twilio (входящий/исходящий SIP)
Realtime:     LiveKit (WebRTC медиасервер)
STT:          Whisper large-v3 (локально) или Deepgram Nova-2 (API)
LLM:          Claude Sonnet / GPT-4o mini  
TTS:          Inworld TTS 1.5 Mini ($0.005/мин, русский есть)
Оркестрация:  Python + LiveKit Agents SDK
```

Этот стек чуть сложнее Gemini end-to-end, но даёт контроль над диалогом и постобработкой транскрипта — критично для техник Соколова (нужно точно отслеживать, что сказал секретарь).
