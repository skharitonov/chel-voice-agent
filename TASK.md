# Задача: прототип голосового AI-агента

**Рабочий каталог:** `C:\git\chel-main\04-voice-agent`

---

## Контекст проекта

Проект — AI SDR для **Челябинского завода электротехники (ЧЗЭ)**. Завод производит взрывозащищённые трансформаторные подстанции (КТПВШ, КТПВМ, КТПРН) для шахт, рудников и ГОКов. Продажи — B2B, средний чек высокий, цикл сделки длинный.

Целевые ЛПР: **главные энергетики** и **главные инженеры** горнодобывающих предприятий. Их контакты нужно находить самостоятельно по открытым источникам (Яндекс Карты, 2GIS, Контур.Компас, ВКонтакте, Telegram).

**Задача** — сделать рабочий прототип голосового AI-агента, который выполняет два сценария:

---

## Сценарий A: Квалификация (Lead Qualification)

**Вход:** номер телефона компании + название компании из базы (Яндекс Карты / 2GIS / Контур.Компас).

**Цель звонка:** выяснить:
1. Есть ли на предприятии КТПВШ/КТПВМ/трансформаторные подстанции?
2. Кто ответственный — как зовут главного энергетика / главного инженера?
3. Когда последний раз меняли подстанции? Есть ли план на ближайший год?

**Скрипт — легенда:** звонок от имени «партнёрской компании», которая готовит технический обзор рынка подземного электрооборудования.

**Выход:** JSON-запись с полями:
```json
{
  "company": "...",
  "phone": "...",
  "qualified": true,
  "lpr_name": "...",
  "lpr_contact": "...",
  "notes": "..."
}
```

## Сценарий B: Поиск ЛПР по методу Соколова (LPR Finder)

**Вход:** номер телефона компании (общий/приёмная) + должность нужного ЛПР (например, «главный энергетик»).

**Цель:** получить ФИО и прямой номер ЛПР у секретаря / другого сотрудника.

**Техника** (из `02-research/telegram/sales/lpr-methods.md`, методы 1–3):

1. Звонит агент: *«Добрый день, пишу письмо вашему главному энергетику — напомните отчество?»*
2. Получает ФИО → *«Так, всё правильно, просто дозвониться не могу — номер не менялся у него? 9XX-XXX-XX-XX — этот?»* (называет случайный номер)
3. Секретарь исправляет → агент записывает реальный номер.

Если добавочного нет — эскалация: *«Я понял, поэтому и звоню. На личный тоже не могу дозвониться — актуальный?»*

**Выход:** JSON с ФИО и мобильным ЛПР.

## Требования к реализации

**Язык:** Python (предпочтительно) или Node.js.

**Платформа для голосового агента — оценить и выбрать одну:**

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| [Vapi.ai](https://vapi.ai) | Готовый SDK, дешёвый тариф, поддержка кастомных LLM | Русский язык через ElevenLabs/OpenAI TTS |
| [Bland.ai](https://bland.ai) | Заточен под cold calling, webhooks | Ограниченная поддержка русского |
| Twilio + OpenAI Realtime API | Полный контроль, нативный русский через GPT-4o | Больше кода |
| [Retell AI](https://retellai.com) | Простой onboarding | Проверить поддержку кириллицы |

**Критерий выбора:** качество русской речи агента и стоимость < $0.10 за звонок для теста.

**Минимальный прототип должен:**
- Принять номер телефона как аргумент командной строки
- Позвонить и провести разговор по скрипту сценария A или B (флаг `--mode A/B`)
- Обрабатывать прерывания, вопросы «кто звонит?», «по какому вопросу?»
- Записать результат в JSON-файл в `results/`
- Логировать транскрипт звонка
