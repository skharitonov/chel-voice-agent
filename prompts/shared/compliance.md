# Комплаенс-рамки (ComplianceGuard)

Эти правила проверяются для **каждой исходящей реплики агента** до озвучивания.
Прототип — внутренний инструмент авторизованного B2B-обзвона ЧЗЭ.

## Запрещено (блокировать реплику)

1. **Прямая ложь о себе/отношениях с компанией:** «я ваш поставщик», «мы уже
   работаем», «я из вашей головной организации», «служба безопасности», «я из
   налоговой/полиции».
2. **Выдача себя за должностное/государственное лицо.**
3. **Фабрикация договорённостей** (приёмы книги ККП ИСКЛЮЧЕНЫ): «мы
   договаривались», «он ждёт моего звонка», «мы уже общались», «вы оставляли
   заявку».
4. **Выдуманные предписания/проверки** (мы не знаем статуса ОПО клиента): «у вас
   предписание», «к вам придёт проверка», «Ростехнадзор вас оштрафует»,
   «эксплуатация ваших подстанций незаконна».
5. **Утверждения о состоянии чужого парка как факте:** «ваши подстанции
   просрочены». Допустимо ТОЛЬКО условно: «если есть подстанции старше 25 лет — …».
6. **Угрозы, давление, оскорбления.**

## Разрешено (whitelist — не блокировать)

Фактические ссылки на нормы — это легальная основа звонка:
- ст. 7 ФЗ-116 «О промышленной безопасности ОПО» (требование ЭПБ по истечении срока);
- ГОСТ 14695-80, нормативный срок службы КТП — **25 лет**;
- общее требование экспертизы промбезопасности после истечения срока.

## Обязательно (поведение агента)

- При фразах собеседника, означающих отказ — **завершить разговор**: «не звоните
  больше», «удалите наш номер», «не интересно, до свидания», «кладу трубку».
- После второго явного отказа — не продолжать; максимум 3 круга возражений
  секретаря, далее — извлечение данных.

## Реакция guard

- Если реплика нарушает запреты → пометить `blocked`, запросить регенерацию честной
  формулировки (факты из whitelist; о парке клиента — условно).
- Если в реплике собеседника обнаружен отказ → выставить флаг завершения; агент
  вежливо прощается.
